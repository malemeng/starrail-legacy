# 驿站扩展包

关闭游戏，将整个 `waypost` 文件夹复制到 Windows 的 `%APPDATA%\Godot\app_userdata\星轨遗产\mods\`。启动时游戏读取 `mods/waypost/fleet.json`。

新游戏里打开船坞，选择护卫舰级的「驿鸥级接驳艇」。它有 52 格货舱，可在有造船设施的自有港建造。整备蓝图上的首炮位换成了中型混合炮塔，向左偏转 35°，射界 140°。舰尾新增内置点防炮，归第 3 武器组。四件出厂武器共用满 16 点装配预算。停靠和跃迁分别有机会触发「最后一套轴承」和「迟到的信标」。

包内舰型用 `base` 引用基础舰的稳定 ID。每个新增舰型 ID 以包名和点开头，例如 `waypost.dispatch`。在 `mounts` 数组中写已有槽位 ID 即可覆盖该槽的指定字段。新增槽位须提供局部坐标 `offset`、朝向 `facing`、射界全角 `arc`、尺寸 `size`（1–3）、武器家族 `family` 和安装形式 `type`（固定或炮塔）。舰首朝 +X，+Y 朝屏幕下方，角度单位为度。新增普通槽位默认留空并归第 1 组。`stock` 指定武器 ID，`group` 可取 1–3，内置槽须指定武器。加载器会检查挂点位于舰体内、武器种类与尺寸兼容、出厂总价符合 OP 预算。

船厂用 `stats.recipe` 定义船体结构用量。改动这个数值、挂点尺寸或机库数量会同时改变用料、所需工时和港口报价。旧扩展里的 `stats.price` 可保留，成交时按当地造价结算。

多个包按文件夹名称排序加载。同一包内出现无效配置时，游戏跳过整个包并写入日志。

「迟到的信标」演示如何在 `events` 声明生命周期钩子、基础权重、逐事件冷却和选择。外域使其权重翻倍，学识达到 9 才能亲自校正，也可支付 ¢12 转交资料，或沿原航线前进。条件与后果的写法可参照工程中的 `data/events/port_and_prize.json`。
